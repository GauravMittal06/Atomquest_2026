# AtomQuest Goal Tracking Portal

## Objective
Build an enterprise-style Goal Setting & Tracking Portal supporting:
- employee goal creation
- manager approvals
- quarterly check-ins
- analytics
- reporting
- audit logs
- admin governance

## User Roles
- Employee
- Manager (L1)
- Admin / HR

## Core Workflow
Draft → Submit → Review → Approve → Lock → Quarterly Check-ins

## Technical Requirements
- Web-based application
- Hosted demo
- Export reports
- Architecture diagram
- Multi-role support
